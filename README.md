# MealPoint — сайт только для подписки на еду

Это один Next.js-проект для MealPoint. Обычных ресторанных заказов и ресторанной корзины в нём нет.

## Клиентский сценарий

1. На главной клиент выбирает обеды последовательно, день за днём.
2. В каждой карточке активна только кнопка следующего доступного дня.
3. Нажатие на центр карточки открывает полноэкранное меню дня: первое, второе, описание, калории и КБЖУ. Стрелками можно листать дни, крестиком закрыть окно.
4. После выбора дней клиент выбирает `Самовывоз` или `Доставка`.
5. Переходит в личный кабинет.
6. Вход/регистрация выполняется по номеру телефона и одноразовому SMS-коду.
7. В кабинете клиент выбирает способ оплаты подписки.
8. После активации подписки выдача при самовывозе списывается через QR. Доставка учитывается логикой подписки.

## SMS-регистрация

Клиентский Telegram Login удалён. Аккаунт идентифицируется подтверждённым номером телефона.

Есть два варианта отправки SMS:

- `SMS_HTTP_URL` + `SMS_HTTP_TOKEN`: сервер отправляет POST JSON `{ phone, message, code }` в ваш SMS API.
- Twilio: `TWILIO_ACCOUNT_SID`, `TWILIO_AUTH_TOKEN`, `TWILIO_FROM`.

Также обязательно задайте `SMS_OTP_SECRET` — длинную случайную строку. Код действует 5 минут, не более 5 попыток проверки; новый код можно запрашивать не чаще раза в минуту.

`SMS_DEV_MODE=true` предназначен только для локальной проверки: код возвращается интерфейсу и печатается в лог. На Railway production оставьте `false`.

## Основные страницы

- `/` — выбор дней подписки и способа получения.
- `/account` — телефонный вход, оплата, активные подписки и QR получения.
- `/manager` — кабинет менеджера.
- `/kitchen` — кабинет кухни.
- `/courier` — кабинет курьера.

## Railway

При старте `scripts/db-init.mjs` применяет `database/schema.sql`. Схема автоматически мигрирует старую Telegram-first таблицу `users`: основным ключом становится UUID, `telegram_id` перестаёт быть обязательным. Старые Telegram-поля оставлены только для безопасной совместимости с уже существующей базой и не используются для клиентского входа.

Скопируйте нужные значения из `.env.example` в Railway Variables.
